# 前端开发课程资料

这套资料用于系统讲解前端开发的核心技术。建议按编号顺序阅读，每一篇都可以独立查阅。

## 学习路线

| 顺序 | 文件 | 主题 | 关键收获 |
| --- | --- | --- | --- |
| 1 | `01-html-structure.md` | HTML 与语义化结构 | 用正确的标签描述内容结构 |
| 2 | `02-css-layout.md` | CSS 与页面布局 | 盒模型、Flexbox、Grid、响应式 |
| 3 | `03-javascript-core.md` | JavaScript 语言核心 | 类型、作用域、函数、数组与对象 |
| 4 | `04-dom-and-events.md` | DOM 与事件 | 选中元素、修改页面、处理交互 |
| 5 | `05-async-and-fetch.md` | 异步与网络请求 | Promise、async/await、调用接口 |
| 6 | `06-tooling-and-modules.md` | 工程化与模块 | npm、打包、ES Modules、Git 协作 |
| 7 | `07-react-basics.md` | 组件化与 React | 组件、props、state、列表渲染 |
| 8 | `08-performance-and-a11y.md` | 性能与可访问性 | 加载优化、语义与键盘可用性 |
| 9 | `cheatsheet.md` | 速查表 | 常用语法与命令集中查阅 |

## 建议学习方式

1. **边读边写**：每篇都带可运行的最小示例，务必在浏览器里亲手敲一遍。
2. **先结构、再样式、后行为**：遇到问题先问「HTML 结构对不对」，再问「CSS 布局对不对」，最后才是 JS。
3. **善用浏览器开发者工具**：Elements / Console / Network / Application 四个面板是前端最主要的调试入口。
