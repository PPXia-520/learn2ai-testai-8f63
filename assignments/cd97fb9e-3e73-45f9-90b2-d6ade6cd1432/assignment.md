# 待办清单（Todo List）小练习

综合运用本课程资料中的 HTML、CSS 布局与 DOM 事件知识，使用原生前端技术实现一个可用的待办清单（Todo List）。

功能要求：

1. **添加**：输入框能新增一条待办事项；
2. **完成**：点击可勾选标记完成，完成项在视觉上有所区分（如删除线）；
3. **删除**：能删除某条事项；
4. **布局**：使用 Flexbox 布局，界面简洁清晰。

成果文件（`index.html`、`style.css`、`script.js`）写入 `work/<你的UUID>/<作业ID>/` 目录，完成后推送并确认分享。
