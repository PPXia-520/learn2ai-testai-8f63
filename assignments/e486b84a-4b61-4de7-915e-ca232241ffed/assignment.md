# 远程数据展示：用户列表

在上一次待办清单的基础上，本次练习把数据源从本地输入扩展到**网络请求**，综合运用课程资料中「DOM 与事件」「异步与网络请求」两篇的知识。

## 目标

使用原生前端技术，从公开接口拉取用户数据并在页面上展示为卡片列表。

接口（无需鉴权，直接可访问）：

```
https://jsonplaceholder.typicode.com/users
```

## 功能要求

1. **拉取数据**：使用 `fetch` + `async/await` 请求上面的接口，获取用户数组；
2. **渲染卡片**：将每个用户渲染成一张卡片，至少展示**姓名、邮箱、公司名**三项；
3. **加载状态**：请求进行中显示「加载中…」提示，请求结束后移除；
4. **错误处理**：请求失败（断网、非 2xx 状态等）时在页面显示友好错误信息，并提供一个「重试」按钮重新发起请求；
5. **搜索过滤**：提供一个输入框，输入时按姓名（或邮箱）过滤卡片，大小写不敏感；
6. **布局**：卡片使用 Flexbox 或 Grid 布局，界面简洁清晰。

## 提示

- 参考 `materials/05-async-and-fetch.md` 第 5 节「用 fetch 调接口」和第 3 节「async / await」；
- 记得判断 `res.ok`，`fetch` 只在网络故障时 reject，4xx/5xx 也会正常 resolve；
- 卡片结构可参考 `materials/04-dom-and-events.md` 中创建与插入元素的写法。
